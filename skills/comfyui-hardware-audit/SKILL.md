# 硬件审计机制（入场审计 → 探针 → 动态能力清单 → 降级）

> **DSH 适配**：本技能来自 WorkBuddy 专家团版。「成员/派单/回执」= 你的分步执行与交付记录，「本团」= 你。单 agent 场景下纪律不变。

证据级：`[实测]` 本机可复现 ｜ `[外核]` URL+日期 ｜ `[待核验]` 没验过别当能跑。

🔴 **禁令（写死在机制里）**：
- 全包禁止「X GB 显存只能跑 Y」式静态档位断言；禁止任何未经逐机型实测的显存参考带。
- 本机数字 = 本机数字。Mac/MPS 统一内存的读数**不得外推成 NVIDIA 通用档位**。
- 报区间不报单点；每个数字带**机器型号 + 内存/显存口径 + 采样时刻 + 采样方式**（`comfyui-sop` 既有纪律）。

## 1. 入场审计（每个 session 开场）

数据源（按可用性取）：
- HTTP `GET /system_stats`（ComfyUI 本体）→ 版本、设备、显存/内存 `[实测·2026-11-03 可用]`。
- MCP `get_system_stats` / `list_models` / `list_model_folders` `[外核·github.com/IO-AtelierTech/comfyui-mcp，2026-11-03 访问；桥本机当日实测起不来，见 comfyui-mcp-bridge 排障]`。
- 盘点 `models/checkpoints/` 等目录：**装了什么跑什么**，没装的模型不进能力清单。

## 2. 小规格探针（能力域逐个试）

- 图像：256px × 8 步 SD1.5 单图（最便宜的存在性证明）。
- 视频：480p × 2s；音频：10s；3D：低分辨率单图；训练：10–20 步小样本。
- 记录：端到端墙钟 + 采样时刻 + 规格；轮询粒度会污染墙钟口径，写明「含调度与轮询」还是「纯采样」。

### 探针卡实测样例（本机，2026-11-03 11:58 UTC+8）

| 项 | 值 |
|---|---|
| 机器 | Mac（Apple Silicon，MPS 后端） |
| 内存口径 | 统一内存 16GB（`vram_total` 17,179,869,184 B，即 `torch_vram_total` 同值） |
| ComfyUI / 依赖 | 0.41.0 ｜ PyTorch 2.14.1 ｜ Python 3.13.12 |
| 采样方式 | HTTP `POST /prompt` 提交（prompt_id `daea4c1d…`），`GET /history/{id}` 轮询（粒度 2s） |
| 探针规格 | SD1.5 `v1-5-pruned-emaonly.safetensors`，256×256×1，8 步，cfg 6.0，euler/normal，seed 42 |
| 结果 | `status: success`，产出 probe_v120_00001_.png（256×256） |
| 端到端墙钟 | 10.1 秒（含加载与 2s 轮询粒度，**非**纯采样耗时） |
| 口径声明 | 单机单次观测；不构成档位；不外推其他机型/系统 |

## 3. 动态能力清单（硬件前提卡，随派单下发）

模板（每 session 一份，数字全来自当次审计/探针）：

```
硬件前提卡 · <session 日期>
机器：<型号+后端>｜内存口径：<统一内存/显存 + 读数>
已装模型：<逐条列，没有就写「无」>
探针结果：<域/规格/墙钟/时刻>
能干什么：<逐条，来源=已装模型+探针通过>
不能干什么：<逐条，来源=缺模型/探针失败>
降级路径：<量化→降分辨率/时长→如实做不到>
```

## 4. 量化降级路径（按序，不硬试）

1. 换量化/压缩权重（GGUF 系；外核：ComfyUI 仓库 QUANTIZATION 文档，2026-11-03 参考；量化加载节点以 `/object_info` 现场为准）。
2. 降分辨率 / 降时长 / 降帧数 / 降 batch。
3. 仍不行 → 如实告知「本机做不到」，把卡在哪一步、差多少资源写清楚；**不硬试爆显存**。

## 5. 云兜底（只指路）

Comfy Cloud / API 节点（`ComfyCloud*`、`ByteDance*`、`Kling*` 等）：如实指路，标**第三方付费 + 账号自理**；帮用户操作工具可做，替用户产出撞资质墙（判据=产出物归属）。
