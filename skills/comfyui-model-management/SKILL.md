# ComfyUI 模型与提示词管理（comfyui-model-management）

> **DSH 适配**：本技能来自 WorkBuddy 专家团版。「成员/派单/回执」= 你的分步执行与交付记录，「本团」= 你。单 agent 场景下纪律不变。

选对模型、写好 prompt、并**先核验存在**——不假设、不替下。

## 1. 模型选型

- **checkpoint（基模）**：按风格目标选（写实 / 二次元 / 3D / 电影感）。确认本机有该权重。
- **LoRA**：叠加风格/角色/概念；确认权重文件名与触发词（部分 LoRA 需特定触发词才生效）。
- **ControlNet / IP-Adapter**：构图控制（姿态/线稿/深度）、参考图注入；确认对应预处理器与模型齐备。
- 所有选型**先核验**：`GET /object_info`（查节点是否注册）或 `ls models/checkpoints/`（经 env-setup 闸门）确认存在，再写入工作流。

## 2. Prompt 工程

- 结构化：主体 + 风格 + 构图 + 光照 + 画质词；负面 prompt 明确排除（畸变/水印/低质/多余肢体）。
- 视频/图生视频：写明镜头运动、帧率、时长意图，供采样器与视频模型节点消费。
- 语言：默认中文需求 → 产出中英双轨 prompt（多数模型吃英文权重更稳）。

## 3. 参数建议（可复现默认值）

| 参数 | 建议 | 说明 |
|---|---|---|
| steps | 20–30 | 质量与耗时权衡 |
| cfg | 6–8 | 文本跟随强度 |
| sampler | DPM++ 2M Karras / Euler a | 常用稳定组合 |
| resolution | 按模型原生训练尺寸 | 避免非整除拉伸 |
| seed | 固定或 -1 随机 | 复现用固定值 |

## 4. 模型红线

- **不替用户下载大模型**：checkpoint/LoRA 体积大、有版权——只选、只核验、不代下。
- 模型效果结论须基于真实生成结果，不可用前就夸。
- `/object_info` 是节点与模型字段的真相源，不凭记忆写。
- **节点存在性核验：先实证，再判断是不是「服务端自报不全」**：`/object_info` 是服务端自报，理论上可能不全。**遇到核心规范节点（如 `EmptyLatentImage`/`KSampler`/`VAEDecode`）未列出时，按以下顺序排查**：① 该节点是否随 ComfyUI 版本变化（改名 / 移除）② 是否未安装 / 未注册——**按节点类别用不同命令，别用同一条**：
   - 自定义 / 社区节点：`ls custom_nodes/` 看目录在不在，再用 `/object_info` 与 `list_nodes` 双向核对。
   - **ComfyUI 内置核心节点**（如本规则点名的 `EmptyLatentImage` / `KSampler` / `VAEDecode`）：它们随 ComfyUI 本体分发，**不在 `custom_nodes/` 里，`ls` 那个目录对它们永远返回「没有」，证明不了任何事**。要查的是 ComfyUI 本体：看启动日志有没有 import failed / 节点未注册；再看 `/object_info` 里该节点所在分类在不在。③ 服务端是否真的漏报。**只有 ①② 都排除后**，才允许凭规范节点库放行。自定义 / 社区节点一律以 `/object_info` 或 `list_nodes` 实证为准。

## 5. 输出物

- prompt 中英双轨（正/负）、模型清单（名称+类型+核验状态）、参数建议表、与节点图的对应说明。

## 6. 判定标准（怎么算选型 / prompt 过关）

- ✅ 每个模型标核验方式：`COMBO 实测` / `ls 实测` / `未核验`——三者不许混写。
- ✅ COMBO 取值域为空的模型，**绝不写进工作流**（如 `loras/` 为 0 仍挂 `LoraLoader` = 必失败）。
- ✅ prompt 中英双轨 + 负面词覆盖畸变 / 水印 / 低质 / 多余肢体。
- ✅ 参数给可复现默认值（steps / cfg / sampler / scheduler / 分辨率 / seed）+ 取舍理由。
- ❌ 不过：没跑就夸「换了这模型效果更好」；性能数字未实测且未标「待实测」；**凭规范节点库放行，却留不下 ①② 的排除证据**。

## 7. 做不到什么（边界）

- **不替用户下载模型**：只核验、只给文件名，落地由用户自己做（完整口径见 comfyui-sop §5）。
- **不保证** prompt 一定出好图：效果必须真跑后由用户判，本团只保证结构完整 + 参数可复现。
- **不判**版权与商用合规（模型许可、生成物商用范围）——归用户与法务（口径见 comfyui-sop §9）。
- **不保证** LoRA / ControlNet 生效：触发词缺失、预处理器版本差异都会导致效果漂移，需实跑确认。
- **不能替代**用户定风格：主题与风格取舍由用户拍板，本团只做翻译与参数化。
